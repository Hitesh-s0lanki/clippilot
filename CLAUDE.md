# ClipPilot

Mini interactive video campaign builder. A user creates a personalised video campaign,
a customer previews it and clicks one of two response options, and the event shows up in
the campaign's analytics. The end-to-end flow matters more than screen count — see
[docs/02-core-user-flow.md](docs/02-core-user-flow.md).

## Frontend structure — non-negotiable

The full spec is in the **`frontend-structure`** skill; load it before you add, move, or
rename anything under `frontend/src`. The short version:

- Routes live in two groups: `app/(auth)/` and `app/(protected)/`. Public customer-facing
  routes (landing, campaign preview) stay outside both, at the `app/` top level.
- **Every route owns a `_components/` folder** next to its `page.tsx`. That is where its
  components go — not in `src/components`, not inline in the page.
- A group-level `_components/` (`app/(protected)/_components/`) holds what two or more
  routes *in that group* share.
- `src/components/` is for what is shared across groups only: `ui/` primitives and
  `layout/` chrome. Nothing route-specific ever lands there.
- **Never import another route's `_components/`.** Needing to is the signal to promote the
  component one level up.

## No fat files

Load the **`frontend-component`** skill before writing a component. The rule it enforces:
a `page.tsx` composes and nothing else, a component file exports one component, and a
screen is built from several small named pieces rather than one long file. A 300-line
`campaign-builder-form.tsx` is a bug in the structure, not a big component.

## Conventions

- Files and folders: `kebab-case`. Components: named `PascalCase` exports matching the
  file name (`campaign-card.tsx` → `CampaignCard`). Default exports only in Next.js
  special files (`page`, `layout`, `error`, `loading`, `not-found`, `route`).
- Imports cross folders through the `@/` alias; a route's own `_components` through `./`.
- Server Components by default. `"use client"` goes on the smallest leaf that needs it.
- HTTP goes through `src/lib/api` only — components never call `fetch` directly.
- Style with the shadcn token utilities defined in `src/app/globals.css`
  (`bg-card`, `text-foreground`, `border-border`, `bg-primary`, …), not raw palette colours.
- Prettier: 100 cols, double quotes, semicolons, trailing commas.
